Сколько же времени, сил, дотфайлов и других файлов конфигураций было утеряно, когда внезапный синий экран выдает Kernel Panic. После этого иногда возникает желание заняться бэкапами.

## Подготовка

Вам понадобится пара флешек - одна для бэкапов (64-128ГБ), а вторая для Live-USB (подойдет любая больше 8ГБ)

## Установка инструментов

В мире дистрибутивов Linux есть 2 инструмента с GUI, которые хорошо выполняют свою задачу по созданию и восстановлению бэкапов. Инструменты CLI я рассматривать не буду. Вот эти инструменты: Timeshift и Deja Dup (иногда называется просто Backups). Timeshift делает снимок всей системы (исключая домашнюю директорию home, и некоторых журналов и логов), а Deja Dup используется для бэкапа домашней директории, места где хранятся ваши личные данные а также настройки пользователя.

Иногда эти инструменты уже есть в система, но если нет, то устанавливаем.

Для Ubuntu, Mint:

```sh
sudo apt update
sudo apt upgrade
sudo apt install timeshift deja-dup
```

Для Arch, Manjaro:

```sh
sudo pacman -Syu
sudo pacman -S timeshift deja-dup
```

## Timeshift

Вставляем флешку, запускаем утилиту **Disks**, форматируем ее в формат `ext4` (все данные на ней будут удалены)

Если у вас Mint или Ubuntu то запускаем Timeshift стандартно через меню, а если Arch то через `sudo timeshift-launcher`.

Далее нажимаем **Create**, выбираем свою флешку и создаем свой первый системный бэкап. После создания он отобразится в списке. Закрываем timeshift.

## Deja Dup

Тут процесс очень похож. Главное выбрать вашу флешку. В остальном просто принимайте стандартные настройки. При желании можете зашифровать данные паролем, когда программа предложит. Восстанавливать этот бэкап нужно если были повреждены или удалены файлы из домашней директории.

## Live-USB

Если у вас **Ubuntu** или **Mint**, то качаем любой их `.iso` файл с официального сайта. Если **Arch**, то скачайте **Manjaro**. Потом записываем на вторую флешку используя **BalenaEtcher** или **Rufus** если есть доступ к Windows.

## Боевое тестирование

Ситуация с Kernel Panic идеально подходит для того чтобы полностью освоить инструменты по созданию и восстановлению резервной копии. Ведь теперь система не грузится и изнутри ничего не пофиксить. Поэтому представим что у вас именно такая ситуация.

Либо сделайте `sudo rm -rf /usr/lib/modules/*`, это сломает вашу систему и вы сможете протестить восстановление в боевом режиме.

Итак, при запуске системы вас встречает Kernel Panic. Но теперь у вас есть бэкапы и инструменты для их восстановления. Втыкаем в компьютер обе флешки. Перезапускаем и нажимаем кнопки чтобы попасть в BIOS. Там в разделе BOOT ставим флешку с установленной Live-USB системой на первое место. Сохраняем и выходим.

Теперь мы должны попасть на меню с Live USB системы, выбираем первый пункт, обычно называется Try OS. Ждем немного и попадаем на рабочий стол. Теперь можно восстанавливать поломанную систему.

Как правило в Live USB уже есть инструменты для восстановления, нам нужен Timeshift. Запускаем его, жмем кнопку **Restore**, выбираем флешку с бэкапами и нажимаем далее. Все восстановится автоматически. После завершения процесса перезагрузите систему. Выньте флешки.

Система вернется к состоянию до того, как были удалены критические файлы и Kernel Panic пропадет. Система запустится в штатном режиме. Теперь у вас есть налаженный процесс на случай поломки Linux.
